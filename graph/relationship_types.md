# CompassGraph Relationship Types

This file defines the standard relationship types used across CompassGraph.

## Definition Relationships

- `defined_as`
- `includes`
- `has_component`
- `example_of`
- `type_of`

## Requirement Relationships

- `requires`
- `depends_on`
- `needs`
- `evaluated_by`
- `measured_by`

## Validation Relationships

- `validated_by`
- `invalidated_by`
- `tested_by`
- `proven_by`
- `supported_by`

## Causal Relationships

- `causes`
- `leads_to`
- `creates`
- `enables`
- `prevents`
- `risks`
- `mitigated_by`

## Sequence Relationships

- `precedes`
- `follows`
- `evolves_into`
- `next_step_is`

## Career Relationships

- `helps_with`
- `applies_to`
- `requires_skill`
- `builds_skill`
- `targets`
- `improves_chance_of`
- `demonstrates`

## Venture Relationships

- `funded_by`
- `serves_customer`
- `solves_problem`
- `uses_business_model`
- `competes_with`
- `scales_through`

## Course Relationships

- `taught_in`
- `part_of`
- `has_assignment`
- `has_deadline`
- `teaches`
